\chapter*{About this book}
\addcontentsline{toc}{chapter}{About this book}

This is the source edition of the \Breadbox{} manual. It is intended to be useful at several levels: as a first book for someone meeting the system for the first time, as a practical handbook for its everyday use, and as a technical reference for people writing software or studying the implementation.

The book is organized so that these audiences can share one volume without being forced through the same reading path. The early parts teach by doing. The middle parts explain how to accomplish real tasks. The later parts describe the programming interfaces and the machine beneath them. Appendices collect material best consulted by subject.

\section*{How to read the examples}
Examples are labelled by where they belong. A Breadbox prompt example is entered at the Breadbox shell. Host commands are entered on the development computer. Source listings are files to be saved or studied, not commands to type verbatim at a prompt.

\section*{Accuracy and applicability}
Breadbox is evolving. Statements in this book should distinguish documented interface guarantees from observed implementation behavior, hardware-specific behavior, and planned work. Platform notes identify where a feature depends on a stock C64, an REU, a compatible disk drive, or a C64 Ultimate with UCI enabled.

This is a working edition. The source repository is authoritative for the manuscript; each published PDF should identify the Breadbox revision and documentation revision it describes.
